# **Pushdown Automata (PDA) Simulator**

## **Project Description**

This project is a web-based **Pushdown Automata (PDA) Simulator** developed using **HTML, CSS, and JavaScript**. The application enables users to input a string and simulate the execution of a Pushdown Automaton to determine whether the string is **accepted** or **rejected** according to the predefined PDA rules.

The simulator provides an intuitive graphical user interface that simplifies user interaction without requiring knowledge of the underlying implementation. During the simulation, users can observe the automaton's state transitions, input processing, and stack operations, making it a useful educational tool for learning formal languages and automata theory.

By leveraging web technologies, the application is lightweight, platform-independent, and can run directly in any modern web browser without additional installation.

---

## **Main Features**

* User-friendly interface for entering input strings.
* One-click simulation process.
* Displays whether the input string is **Accepted** or **Rejected**.
* Real-time visualization of stack operations (Push and Pop).
* Displays the current state and transition path during execution.
* Step-by-step execution mode for educational purposes.
* Reset functionality for testing multiple input strings.
* Responsive design compatible with desktop and mobile browsers.

---

## **Technology Stack**

* **HTML5** – Provides the structure of the web application.
* **CSS3** – Designs the user interface with a clean and responsive layout.
* **JavaScript (ES6)** – Implements the Pushdown Automata algorithm and handles all user interactions dynamically.

---

## **Objectives**

The main objective of this project is to automate the execution of a Pushdown Automaton while providing an interactive and user-friendly environment. It helps users understand how a PDA processes input strings, manages its stack, and determines language membership through simulation.
